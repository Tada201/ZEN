# Performance & Design Principles

## Function over Form
Prioritize utility and performance in all UI and UX developments. 
Every unique animation, transition, or specialized UI feature must:
1. Serve a clear functional purpose.
2. Be useful for the user's workflow.
3. Not result in unnecessary performance waste on purely decorative elements.

## Guidelines
- Avoid heavy CSS animations that don't provide feedback.
- Remove legacy "scanline" or "CRT" effects if they interfere with readability or waste GPU cycles.
- Focus on snappy, responsive interactions.
