# Zen

Zen is a high-fidelity, Palantir-inspired OSINT (Open Source Intelligence) data analysis platform built with Tauri 2.0 and React 19.

## Core Mission: Regenerative Spatial Intelligence
Zen is a high-fidelity "God Mode" platform designed for community healing and transparency. It leverages the principle of **Sousveillance** (the reverse panopticon) to transform global telemetry—aviation, maritime, and orbital—into actionable insights for environmental and social vitality.

## Core Capabilities
- **Agentic GIS**: Multi-agent orchestration (LangGraph) for automated OSINT investigations.
- **4D Precision**: High-precision WGS84 globes (CesiumJS) with temporal voyage replay.
- **Resilient Telemetry**: Sub-millisecond ingestion of 20,000+ moving entities via binary transport.
- **Sovereign Operations**: Full compliance with localized data protection laws (Vietnam PDPL/A05).

## Tech Stack
- **Backend**: Rust (Axum/Tauri 2.0) & Python (FastAPI/LangGraph)
- **Frontend**: React 19, Tailwind CSS 4, CesiumJS, WebGPU
- **Storage**: Weaviate (Vector), Redis (Cache), SurrealDB (Local)
- **Protocol**: Model Context Protocol (MCP) for tool-chaining
